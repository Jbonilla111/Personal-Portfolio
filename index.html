CleanCrave

CleanCrave is a web application designed to help users transition to healthier eating without giving up their favorite foods. The app suggests smarter ingredient swaps and integrates an AI-powered nutrition chatbot, Foodie, to educate and motivate users with positive reinforcement. It also uses a Maps API to help users locate nearby stores and restaurants offering healthier options, making sustainable lifestyle changes more accessible.

YouShare

YourShare is a community-driven platform that enables users to share and borrow items locally to reduce waste and encourage sustainability. Built with React and Firebase, the application supports secure user authentication, data storage, and intuitive navigation. The project emphasizes thoughtful UX design and demonstrates the use of modern frontend frameworks to strengthen community connections through technology.

Live Repo

HerHealthyHaven

HerHealthyHaven is an informational website created to support and educate women about ovarian cysts and related health topics such as PCOS, ovarian cancer, and mental health. The site presents complex medical information in an accessible and compassionate way, using interactive JavaScript features and clean visual design to enhance engagement. This project reflects a strong commitment to building human-centered, impact-driven technology.
